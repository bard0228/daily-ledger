# 日常記帳本 (Daily Ledger PWA)

個人日常收支與分類統計記帳網頁 App，採用簡約 iOS 液態玻璃（Liquid Glass）風格、低飽和莫蘭迪調色盤、全元素圓角倒角、微浮起動畫與流暢手風琴展開特效。支援 Progressive Web App (PWA)，可在 Android / iOS 裝置上一鍵安裝至手機主畫面作為獨立全螢幕 App 運行。

## 🌟 特色功能

- **📱 支援 Android / iOS 行動裝置 PWA 安裝**：
  - 具備 Web App Manifest (`manifest.json`) 與專屬鮭魚壽司 App 圖示（192x192、512x512、apple-touch-icon）。
  - 整合 Service Worker (`sw.js`) 進行靜態資源快取。
  - 在 Android Chrome 瀏覽器中可直接點選「安裝應用程式」或「加到主畫面」，點開即為純淨全螢幕原生體驗。
- **☁️ 即時串接 Google 試算表（Google Sheets）**：
  - 前端以無快取即時 CSV API 自動讀取 Google 試算表最新帳目。
  - 每次透過 AI 對話或指令記帳後，網頁打開即秒級同步最新數據，無需重新打包部署。
- **🎨 簡約 iOS 液態玻璃（Liquid Glass）視覺**：
  - 溫暖霧灰漸層背景與多層次毛玻璃效果（`backdrop-filter: blur(26px)`）。
  - 1px 高光折射邊框與柔和漫反射立體陰影。
  - 全元素精準圓角倒角（區塊 30px、卡片 22px、按鈕與選單 18px、標籤 10px）。
- **✨ 絲滑手風琴（Accordion）動畫與微浮起互動**：
  - 按鈕、下拉選單、搜尋欄與指標卡靠近時自然微浮起（Hover/Touch Lift）。
  - 月份選單與搜尋結果採用 Spring 彈簧貝茲曲線，展開與收合皆具備流暢手風琴動畫。
- **📊 完整收支與大類統計**：
  - 月度三大核心指標：本月收入、本月支出、本月結餘。
  - 低飽和莫蘭迪環形圖（Donut Chart）大類占比與明細表。
  - 當月流水帳清單與關鍵字即時搜尋合計。
  - 左下角液態玻璃快捷 Dock（返回壽司主傳送門與重新整理）。

## 📱 手機安裝說明 (Android Chrome)

1. 使用 Android 手機的 **Chrome** 瀏覽器開啟專屬網址。
2. 點擊瀏覽器右上角的三個點選單（`⋮`）。
3. 點選 **「安裝應用程式」** 或 **「加到主畫面」**。
4. 點擊「安裝」後，手機桌面就會出現專屬鮭魚壽司圖示的「日常記帳本」App！
